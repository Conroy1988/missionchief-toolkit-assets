Toolkit help

Extension 0.21.0 · UI test candidate · Toolkit 10.18.1

First setup

  1. Open MissionChief UK and sign in.
  2. Disable your Map Command Toolkit userscript and any duplicate Toolkit extension.
  3. Open the extension popup, enable Toolkit, then Apply & reload.
  4. Open Tasks & settings → Settings manager to import an existing safe settings backup.

The extension copies ordinary userscript settings once, then saves separately. Presets are stored per game account and have their own export/import controls.

Operations

ToolWhat it changes
Patient transport sweepReleases eligible alliance patient transports. Own vehicles and prisoner transports are excluded.
Staff recruitmentUpdates selected stations’ hiring phase and desired personnel.
Training coursesCreates mapped academy courses and shares them with the alliance. Appropriate alliance permissions and academy naming are required.
Building expansionsPurchases selected native Credit upgrades within the confirmed budget.
Copy station iconsCopies an owned station’s icon to eligible same-type stations under the selected replacement rule.

Choose scope → scan → review findings and targets → confirm the current plan → review results. Expansions revalidate prices and eligibility before confirmation. Presets apply preferences only; they never select targets or start a scan or run.

Tasks and recovery

A task is running in another tab

Open Tasks & settings → Task centre → Open task tab. Stop it there or wait for it to finish. Keep the owning game tab open while working.

A task stopped, failed or was interrupted

Review completed, skipped and failed counts and the game’s current state. A request already sent may still finish. Correct the cause, then scan again. Do not assume an unverified action failed and repeat it blindly.

Settings are unsaved or changed in another tab

Keep the tab open and export a settings backup from the settings manager. Do not reload until you have preserved the values you need. A conflicting change is not retried automatically. After backing up, reload and review the current settings before importing selected groups.

The toolkit does not appear

Check the popup’s Connection & compatibility section. Disabled: enable and Apply & reload. Duplicate Toolkit: disable the old userscript or second copy. Unsupported page: open MissionChief UK. Startup failure: export diagnostics, then reload once. If it repeats, include the export and your extension/browser versions in a support report.

Discord reports

Open the extension popup → Discord integrations. Save a webhook and channel label there, then Check connection. In-game, prepare a finance report, sweep report or Operational SITREP. Review the report and optional chart in the Discord screen before Confirm & send. Reports never post automatically after a sweep. If delivery is uncertain, check Discord before preparing another report. A draft expires after 30 minutes. Use Forget destination to remove the saved webhook and draft.

Update safely

Store installation: your browser manages extension updates. An older store version can remain installed while a new submission is under review.

Chrome/Brave unpacked: export a settings backup, replace the files in the same extension folder with the new ZIP contents, reload that existing extension entry, then reload MissionChief.

Orion iOS: use the release ZIP directly with Orion’s file-install option. Prefer updating the existing entry. Export settings and presets before any removal/reinstallation, which can remove local extension data.

Keep the last working ZIP. If a candidate breaks startup, disable it and restore the previous package using the existing entry where possible. Settings added in a newer version may not be understood by an older one.

Report a problem

Include extension version, Toolkit version, browser/app version, desktop or iOS, what you did, what you expected and what happened. Export diagnostics from the popup; it excludes settings, account identifiers and game records. Screenshots and settings/preset backups may contain names or game identifiers—review them before sharing.
