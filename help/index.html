Guide for Toolkit v9.0.0

The One We Knew Before

Version 9 unifies every retained command system behind six task-led sections while preserving MissionChief-native authority, deterministic teardown and all eight interface themes.

Install ToolkitReleases

What changes in v9.0.0

The Command Interface now uses Map, Missions, Finance, Locations, Appearance and Settings. Desktop gains a wider command workspace, Tablet uses a compact navigation rail, and iOS Mobile keeps all six sections visible in a full-width bottom sheet. The map command bar now groups Visibility, Intelligence, Dashboard and Performance controls with explicit ON, OFF and ACTIVE states.

Mission Age map timers

Compact age badges above personal missions. Press 6 to toggle them.

Mission Value

Shows verified mission value in opened MissionChief windows without replacing native controls.

Patient Transport Sweep

Opens verified alliance-owned FMS 5 patient vehicles and uses MissionChief’s native Discharge patient control.

Transport Watcher

Identifies patient and prisoner transport demand.

Shows priority incidents that still need your attendance. A mission leaves when one of your own units reaches FMS 4 and can re-enter after your final on-scene unit leaves.

Alliance Credits

Adds mission-value and eligibility-aware alliance filtering.

Financial intelligence

Reconciles income, spending and variance, with Simple, Informative or The Wolf reports sent through the saved Discord webhook.

Smart Bookmark Labels

Creates compact places, pins, labels and touch previews.

Economy Mode

Suppresses non-essential effects and expensive refresh work.

Eight complete interface systems

Map Command, Cyberpunk, Fallout 4, Umbrella, Factorio, 007 Intelligence, Hyrule Command and The Godfather share the same retained native feature set.

Device support

Desktop, Tablet/iPad and iOS Mobile Mode remain supported with safe-area handling, 44px touch targets, orientation recovery and responsive panels.

Privacy

Most settings stay in the browser. Financial reporting uses only the saved Discord webhook supplied by the user; exported settings containing it should be treated as private.

The Godfather interface

The eighth complete interface system uses original Toolkit-made old-money command artwork: marionette command seal, oxblood wax, velvet rose, tailored pinstripe, polished wood and antique brass. Selecting it pairs the The Godfather Offer payout. Its MP3 remains lazy and is requested only when that payout is played. Reduced-motion and Economy Mode disable non-essential effects, while operational status colours remain protected.

Alliance Member Manager

Enable Alliance Member Manager from Map → Alliance Operations. On an alliance member-list page it adds English role, activity, sorting and direction controls without replacing MissionChief profile or administration actions.

  • Filter by alliance role or current online/offline state.
  • Sort by original order, member name, alliance role or current activity.
  • Select Load All Member Pages to fetch remaining pages sequentially and de-duplicate members.
  • No additional pages are requested until that button is pressed.
  • Turning the feature off aborts active loading and restores the original current-page rows.

Patient Transport Sweep — native vehicle workflow

The sweep opens the mission, opens the flashing alliance-owned FMS 5 vehicle, locates and clicks the native Cancel Transport control whether rendered as a link, button or submit input, recognises Patient isn’t transported, and repeats. The alternative native label Discharge patient remains supported.

Incident Command Wire — unattended missions

The wire excludes a qualifying mission only after one of your own vehicles reaches MissionChief’s FMS 4 on-scene state. Selection and FMS 3 responding do not remove it, alliance-only attendance is ignored, and the mission can re-enter when your final on-scene unit leaves. The current card advances safely while Pause/Play, the counter and expanded queue remain synchronized.

Same-value UI write suppression

Toolkit v9.0.0 retains the v8.3.2 guarantee: it locates the current live command bar and settings panel on every update, but writes a class, attribute, style, text value or form value only when it differs. This avoids repeated DOM mutation traffic without caching stale MissionChief elements.
