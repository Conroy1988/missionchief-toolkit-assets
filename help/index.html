Eight complete interface systems

Map Command, Cyberpunk, Fallout 4, Umbrella, Factorio, 007 Intelligence, Hyrule Command and The Godfather share the same retained native feature set.

Device support

Desktop, Tablet/iPad and iOS Mobile Mode remain supported with safe-area handling, 44px touch targets, orientation recovery and responsive panels.

Privacy

Most settings stay in the browser. MissionChief UK Guide requests use only the Guide's three public versioned collections and send no account, alliance, mission-instance, vehicle, location, cookie, token or webhook data. The full transfer includes the saved Discord webhook and Financial Archive only inside authenticated encryption; Safe Export excludes those private values.

The Godfather interface

The eighth complete interface system uses original Toolkit-made old-money command artwork: marionette command seal, oxblood wax, velvet rose, tailored pinstripe, polished wood and antique brass. Selecting it pairs the The Godfather Offer payout. Its MP3 remains lazy and is requested only when that payout is played. Reduced-motion and Economy Mode disable non-essential effects, while operational status colours remain protected.

Alliance Member Manager

Enable Alliance Member Manager from Map → Alliance Operations. On an alliance member-list page it adds English role, activity, sorting and direction controls without replacing MissionChief profile or administration actions.

  • Filter by alliance role or current online/offline state.
  • Sort by original order, member name, alliance role or current activity.
  • Select Load All Member Pages to fetch remaining pages sequentially and de-duplicate members.
  • No additional pages are requested until that button is pressed.
  • Turning the feature off aborts active loading and restores the original current-page rows.

Patient Transport Sweep — native vehicle workflow

The sweep opens the mission, opens the flashing alliance-owned FMS 5 vehicle, locates and clicks the native Cancel Transport control whether rendered as a link, button or submit input, recognises Patient isn’t transported, and repeats. The alternative native label Discharge patient remains supported.

Incident Command Wire — unattended missions

The wire excludes a qualifying mission only after one of your own vehicles reaches MissionChief’s FMS 4 on-scene state. Selection and FMS 3 responding do not remove it, alliance-only attendance is ignored, and the mission can re-enter when your final on-scene unit leaves. The continuous reel, counter and expanded queue remain synchronized without routine layout reconciliation seeking the reel backwards.

Operational Pressure Board and SITREP

The board includes personal missions plus alliance missions you have joined. Available personal vehicles are allocated once across the complete current demand picture, so a single specialist unit cannot cover several missions on paper. Focus, Open and Pin are navigation only. The SITREP uses the same snapshot and the saved Finance webhook only after the manual Generate & Post action.

MissionChief UK Knowledge Link

Every known Pressure Board requirement exposes a read-only dossier containing qualifying units, numeric type IDs, capability alternatives, crew ranges, training courses, academies, durations and associated personnel. Opening the dossier uses a fresh cached copy where possible; Refresh Guide data explicitly requests the three schema-validated public Guide collections. A bounded stale copy and the embedded catalogue preserve useful evidence when the Guide is unavailable. Unknown live labels remain visible as Catalogue Drift and the report link opens a review-before-submit GitHub form without player identifiers.

v9.3 Command Experience

Toolkit Doctor runs only when selected and its copied report omits webhook URLs, tokens, player identity, balances, coordinates and mission data. Full-Screen Map is restored from saved settings but always exposes an exit button and Escape. On Tablet, native map long-press opens the six-action Quick Wheel; its slots are configured in Settings and map dragging is restored when it closes. Density choices are saved separately for Desktop and Tablet. Encrypted Export requires a passphrase of at least 12 characters and authenticates the complete transfer against alteration; losing the passphrase makes recovery impossible. Safe Export is plain JSON without Discord webhook, archive identity or financial history. The Update Briefing is shown once only after the interface is safe to interrupt, can be disabled and can always be reopened manually.

Same-value UI write suppression

Toolkit v9.3.0 retains the v8.3.2 guarantee: it locates the current live command bar and settings panel on every update, but writes a class, attribute, style, text value or form value only when it differs. This avoids repeated DOM mutation traffic without caching stale MissionChief elements.
