# Extension changelog

Store availability is determined by Google review. These are extension versions; the historical 10.x userscript/core version is a different version sequence.

## 1.2.5 — submitted 14 September 2026

- Home Response Unit Switcher: dispatch-centre and type filters, faster shared preview checks, category-aware native Credit purchase links, labelled full-slot estimates and saved recovery.
- Hospital upgrades: direct target levels 1–30, current Credit balance parsing and verification at maximum level.
- Includes the Home Response Builder and all 1.0.0 features below.
- 111 automated checks passed. Full live replacement completion after the latest full-slot fix still needs confirmation.

## 1.0.0 — extension release candidate

Consolidated the tested 0.23.14 features for Store submission: Home Response Builder, map boundary selection, up to 1,000 proposals, mapped-water checks, existing-building spacing, nearest dispatch centres, persistent icon catalogues, saved queues and stage timings.

## 0.23.0–0.23.14 — development builds

Iterative Home Response planning, recovery, performance, navigation, dispatch-centre and icon-selector improvements. Test ZIPs were supplied separately from Store releases.

## 0.22.3 — extension baseline

Floating map controls and Game Guide alongside Menu, with Operations, finance and optional Discord reporting. The recovered packaged baseline is preserved in `recovered-0.22.3/`.
