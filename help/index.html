Guide for Toolkit v8.1.1 candidate

The One We Knew Before

Version 8 adds The Godfather as a complete interface system while preserving the v7 native MissionChief product boundary, retained command systems and deterministic teardown.

Install stable v7Releases

What changes in v8.1.1

The Godfather becomes the eighth complete interface system, with original Toolkit-made artwork and a lazy theme-scoped Offer payout sting. Production remains on verified v7.1.6 until the guarded v8 release pipeline completes.

Native Toolkit systems

Mission Age map timers

Compact age badges above personal missions. Press 6 to toggle them.

Mission Value

Shows verified mission value in opened MissionChief windows without replacing native controls.

Patient Transport Sweep

Opens verified alliance-owned FMS 5 patient vehicles and uses MissionChief’s native Discharge patient control.

Transport Watcher

Identifies patient and prisoner transport demand.

Resource Gap

Compares active demand with nearby personal vehicle availability.

Vehicle Code Status

Summarises live fleet response codes, descriptions and counts.

Custom Vehicle Badges

Shows Own Vehicle Categories beside native vehicle types.

Incident Command Wire

Shows one complete priority incident at a time with previous, pause, next and expanded-queue controls.

Alliance Credits

Adds mission-value and eligibility-aware alliance filtering.

Financial intelligence

Reconciles income, spending and variance, with reports sent through the saved Discord webhook.

Smart Bookmark Labels

Creates compact places, pins, labels and touch previews.

Economy Mode

Suppresses non-essential effects and expensive refresh work.

Eight complete interface systems

Map Command, Cyberpunk, Fallout 4, Umbrella, Factorio, 007 Intelligence, Hyrule Command and The Godfather share the same retained native feature set.

Device support

Desktop, Tablet/iPad and iOS Mobile Mode remain supported with safe-area handling, 44px touch targets, orientation recovery and responsive panels.

Privacy

Most settings stay in the browser. Financial reporting uses only the saved Discord webhook supplied by the user; exported settings containing it should be treated as private.

The Godfather interface

The eighth complete interface system uses original Toolkit-made old-money command artwork: marionette command seal, oxblood wax, velvet rose, tailored pinstripe, polished wood and antique brass. Selecting it pairs the The Godfather Offer payout. Its MP3 remains lazy and is requested only when that payout is played. Reduced-motion and Economy Mode disable non-essential effects, while operational status colours remain protected.
