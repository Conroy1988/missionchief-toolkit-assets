# MissionChief Map Command Toolkit — moved to Chrome Web Store

The Tampermonkey/userscript edition is no longer supported. Install the [Chrome extension](https://chromewebstore.google.com/detail/lmnojpchebgcochdfnfjmnficicnaaoc) and follow [the migration guide](https://github.com/Conroy1988/missionchief-toolkit-assets/blob/main/docs/MIGRATING_FROM_USERSCRIPT.md). Export settings before disabling the old Toolkit script. Keep Tampermonkey for other scripts if needed. Do not run both Toolkit editions together.
