Privacy-safe first-party analytics

The Toolkit reports only aggregate version adoption, coarse device and route classes, bounded feature demand, startup performance bands and bounded error categories. It sends no visitor identifier, player name, alliance or gameplay data, IP-derived identity, free text, full user agent, referrer or analytics cookie. Global Privacy Control and Do Not Track stop local analytics state and transmission.

Privacy

Most settings stay in the browser. MissionChief UK Guide requests use only the Guide's three public versioned collections and send no account, alliance, mission-instance, vehicle, location, cookie, token or webhook data. The full transfer includes the saved Discord webhook and Financial Archive only inside authenticated encryption; Safe Export excludes those private values.

The Godfather interface

The eighth complete interface system uses original Toolkit-made old-money command artwork: marionette command seal, oxblood wax, velvet rose, tailored pinstripe, polished wood and antique brass. Selecting it pairs the The Godfather Offer payout. Its MP3 remains lazy and is requested only when that payout is played. Reduced-motion and Economy Mode disable non-essential effects, while operational status colours remain protected.

Alliance Member Manager

Enable Alliance Member Manager from Map → Alliance Operations. On an alliance member-list page it adds English role, activity, sorting and direction controls without replacing MissionChief profile or administration actions.

  • Filter by alliance role or current online/offline state.
  • Sort by original order, member name, alliance role or current activity.
  • Select Load All Member Pages to fetch remaining pages sequentially and de-duplicate members.
  • No additional pages are requested until that button is pressed.
  • Turning the feature off aborts active loading and restores the original current-page rows.

Patient Transport Sweep — native vehicle workflow and completion report

The sweep opens the mission, opens the flashing alliance-owned FMS 5 vehicle, locates and clicks the native Cancel Transport control whether rendered as a link, button or submit input, recognises Patient isn’t transported, and repeats. The alternative native label Discharge patient remains supported.

When the sweep finishes, its aggregate report remains visible until dismissed or replaced and survives a page reload. It records missions checked, eligible and completed missions, patients cleared, skipped actions, errors, processed patients, success rate, duration, completion time and final status. If a valid Discord webhook is already saved in Finance, the same snapshot posts automatically once. No mission name, mission ID, player identity or alliance identity is included. A failed webhook never changes the sweep result and exposes a deliberate retry.

Incident Command Wire — unattended missions

The wire excludes a qualifying mission only after one of your own vehicles reaches MissionChief’s FMS 4 on-scene state. Selection and FMS 3 responding do not remove it, alliance-only attendance is ignored, and the mission can re-enter when your final on-scene unit leaves. The continuous reel, counter and expanded queue remain synchronized without routine layout reconciliation seeking the reel backwards.

Operational Pressure Board and SITREP

The board includes personal missions plus alliance missions you have joined. Available personal vehicles are allocated once across the complete current demand picture, so a single specialist unit cannot cover several missions on paper. Focus, Open and Pin are navigation only. The SITREP uses the same snapshot and the saved Finance webhook only after the manual Generate & Post action.

MissionChief UK Knowledge Link

Every known Pressure Board requirement exposes a read-only dossier containing qualifying units, numeric type IDs, capability alternatives, crew ranges, training courses, academies, durations and associated personnel. Opening the dossier uses a fresh cached copy where possible; Refresh Guide data explicitly requests the three schema-validated public Guide collections. A bounded stale copy and the embedded catalogue preserve useful evidence when the Guide is unavailable. Unknown live labels remain visible as Catalogue Drift and the report link opens a review-before-submit GitHub form without player identifiers.

v9.3 Command Experience

Toolkit Doctor runs only when selected and its copied report omits webhook URLs, tokens, player identity, balances, coordinates and mission data. Full-Screen Map is restored from saved settings but always exposes an exit button and Escape. On Tablet, native map long-press opens the Quick Wheel; v10 expands it to four through eight slots and map dragging is restored when it closes. Density choices are saved separately for Desktop and Tablet. Encrypted Export requires a passphrase of at least 12 characters and authenticates the complete transfer against alteration; losing the passphrase makes recovery impossible. Safe Export is plain JSON without Discord webhook, archive identity or financial history. The Update Briefing is shown once only after the interface is safe to interrupt, can be disabled and can always be reopened manually.

v9.4 Toolkit Command Palette

Open the Palette from the permanent map control, Settings, a configured Tablet Quick Wheel slot or K outside an editable field. Type a mission name, vehicle callsign, building, Wakefield, stuck vehicles or full screen. Exact titles and phrases rank first. Arrow keys, Home/End, Enter, Escape, touch and contained Tab focus are supported. Mission results use existing focus logic; vehicle and building results locate existing markers or use MissionChief’s native window. The Palette adds no request, poller, observer or scheduler, and destructive maintenance, Discord posting and automatic dispatch actions are excluded.

v10 Personalisation Studio

The Layout Builder keeps separate control order, visibility, dock position and panel geometry for Desktop, Tablet and iOS. Theme Studio accepts validated colours and bounded surface values; portable theme codes contain visual choices only. The Quick Wheel uses four through eight slots with safe actions, Quick Places, bookmarks or filtered Palette searches. Backup Centre retains the authenticated encrypted full transfer and secret-free safe export, and adds five bounded local state snapshots. The Setup Wizard runs automatically only for a genuinely fresh install. Sounds are synthesised locally, browser permission is explicitly requested, and alerts reuse existing mission lifecycles without a new request, poller, timer or observer.

v10.1 Command Experience

What’s New & Feature Beacon opens each new route directly and leaves a NEW marker until visited. Desktop right-click and Tablet/iOS marker long-press expose contextual focus, native-open and local-search actions only. Complete MissionChief Reskinning is optional and reversible. Toolkit Safe Mode takes a bounded secret-free settings snapshot before transitions, suspends optional modules and preserves Settings, Toolkit Doctor, export, recovery and a guaranteed exit; it does not overwrite original feature choices, Discord webhook or Financial Archive data.

v10.2 Operational Map Flow

Unit Locator & Follow Mode searches personal vehicles by caption, ID, type, station and FMS/status, never dispatches, and stops on manual map movement, marker loss, Safe Mode or teardown. One-Click Session Cleanup previews and confirms a strict transient-state allowlist while protecting settings, layouts, themes, profiles, bookmarks, recovery snapshots, secrets, Discord webhook, Financial Archive history and MissionChief data. Mission Progress Rings and Alliance Chat Mission Previews were retired in v10.2.3, leaving MissionChief's native markers and Alliance Chat untouched.

Same-value UI write suppression

Toolkit v10.6.1 retains the v8.3.2 guarantee: it locates the current live command bar and settings panel on every update, but writes a class, attribute, style, text value or form value only when it differs. This avoids repeated DOM mutation traffic without caching stale MissionChief elements.
